Course Information

Cyber Basics (CB)

Learn fundamental computer skills, internet safety, email communication, and basic digital tools for everyday use.

Coding Fundamentals (CF)

Introduction to programming concepts, logic building, and basic coding using languages like Python and JavaScript.

Digital Marketing Essentials (DME)

Learn social media marketing, SEO basics, email campaigns, and strategies to promote businesses digitally.

AI and Data Literacy (ADL)

Understand AI concepts, data analysis, machine learning basics, and how to make data-driven decisions.
